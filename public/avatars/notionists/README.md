# Static Notionists avatars

Twenty SVGs generated once using DiceBear 9.x Notionists, by Zoish.
Style: https://www.dicebear.com/styles/notionists/ — CC0 1.0.
Source: https://github.com/dicebear/dicebear

The app serves these files directly. No generation script, DiceBear runtime dependency, or external API request is needed.
